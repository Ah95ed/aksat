توثيق API نظام إدارة الأقساط

واجهة REST بصيغة JSON، مبنية بـ PHP وتعتمد على JWT. هذا المستند موجّه لمبرمج تطبيق Flutter، وكل ما يحتاجه للتعامل مع النظام موجود هنا دون أي وصول مباشر لقاعدة البيانات.

البدء السريع

Base URLhttps://aksat.store/api/ (يتغير حسب دومين العميل)
صيغة الطلبJSON مع الهيدر Content-Type: application/json
صيغة الرددائماً { "success": bool, "data": ..., "message": "..." }
المصادقةتوكن JWT يُرسل في الهيدر (انظر قسم المصادقة)
مدة التوكن24 ساعة، ولا يوجد refresh token، فيُعاد تسجيل الدخول بعد انتهائه
عزل البياناتكل مستخدم يرى ويعدّل بياناته فقط، ولا حاجة لإرسال user_id في أي طلب

مسار كل endpoint ينتهي بـ .php، مثل /api/products.php وليس /api/products.

قواعد عامة

افحص success دائماً وليس كود HTTP فقط بعض أخطاء التحقق (حقل ناقص، بيانات غير صالحة في المشترين والمخزن مثلاً) تعيد HTTP 200 مع "success": false ورسالة الخطأ في message. اعتمد على success أولاً، ثم على كود HTTP للحالات 401 و403 و429.
  • الأرقام المالية (price, amount, total_price ...) عمود DECIMAL في القاعدة، وتصل كنص مثل "25000.00". والمعرفات الراجعة بعد الإضافة (sale_id وid في المشترين) تصل كنص أيضاً. لذلك حوّل أي رقم قبل استخدامه بـ double.tryParse(v.toString()) ولا تفترض نوعه.
  • العملة قيمتان فقط: USD وLOCAL (الدينار أو العملة المحلية، والاسم والرمز من الإعدادات).
  • التواريخ بصيغة YYYY-MM-DD عند الإرسال، وحقول created_at بصيغة YYYY-MM-DD HH:MM:SS.
  • حالة القسط status: pending أو paid أو late. ويتحول pending إلى late تلقائياً عند تجاوز تاريخ الاستحقاق.
  • حالة عملية البيع status: active أو completed (تصبح completed عند دفع كل الأقساط).
  • DELETE يمرر المعرف في الرابط: ?id=5 وليس في الجسم.
  • لا تستخدم admin.php، فهو للوحة الإدارة على الويب فقط.

حالات الفشل المتعلقة بالدخول

الحالةالمعنىتصرف التطبيق
401بيانات دخول خاطئة، أو توكن ناقص أو منتهٍ أو غير صالحامسح التوكن وأعد المستخدم لشاشة الدخول
403اشتراك المستخدم موقوف أو منتهٍ. في /login.php يأتي data.code = "SUBSCRIPTION_STOPPED" ومعه data.whatsappاعرض رسالة الإيقاف مع زر تواصل عبر واتساب للإدارة، ولا تعدّه خطأ اتصال
429محاولات دخول فاشلة كثيرة (5 محاولات خلال 5 دقائق تعني حظر 15 دقيقة)، وتجد المدة في data.retry_after_secondsاعرض المدة المتبقية للمستخدم

الاشتراك يُفحص أيضاً مع كل طلب لاحق، فإذا أوقفته الإدارة أثناء استخدام التطبيق يأتيك 403 في أي endpoint.

الإعدادات /settings.php

المفاتيح المسموحة هي الخمسة أعلاه فقط، وأي مفتاح آخر يعيد 400. القيمة النصية بحد أقصى 5000 حرف، وexchange_rate رقم أكبر من 0.

مثال Dart (حزمة dio)

import 'package:dio/dio.dart';

class AksatApi {
  AksatApi(this.baseUrl) {
    _dio = Dio(BaseOptions(
      baseUrl: baseUrl,                       // 'https://aksat.store/api/'
      headers: {'Content-Type': 'application/json'},
      validateStatus: (_) => true,            // نعالج 401/403/429 بأنفسنا
    ));
    _dio.interceptors.add(InterceptorsWrapper(onRequest: (o, h) {
      if (_token != null) {
        o.headers['Authorization'] = 'Bearer $_token';
        o.headers['X-Authorization'] = 'Bearer $_token';
      }
      h.next(o);
    }));
  }

  // أنشئ الأصناف SessionExpired و SubscriptionStopped و ApiError حسب تصميم تطبيقك
  final String baseUrl;
  late final Dio _dio;
  String? _token;   // خزّنه في flutter_secure_storage

  Future<Map<String, dynamic>> _send(Future<Response> req) async {
    final res = await req;
    final body = Map<String, dynamic>.from(res.data as Map);
    if (res.statusCode == 401) throw SessionExpired();          // ارجع لشاشة الدخول
    if (res.statusCode == 403) throw SubscriptionStopped(body); // اعرض رسالة الإيقاف
    if (body['success'] != true) throw ApiError(body['message']?.toString() ?? 'خطأ');
    return body;
  }

  Future<void> login(String email, String password) async {
    final body = await _send(_dio.post('login.php',
        data: {'email': email, 'password': password}));
    _token = body['data']['token'];
  }

  Future<List> products() async =>
      (await _send(_dio.get('products.php')))['data'] as List;

  Future<void> payInstallment(int id, {String? paidDate}) =>
      _send(_dio.put('installments.php',
          data: {'id': id, 'action': 'pay', if (paidDate != null) 'paid_date': paidDate}));
}

double toNum(dynamic v) => double.tryParse(v?.toString() ?? '') ?? 0;

أكواد الأخطاء

HTTPمتى
200 + success:falseخطأ تحقق في بعض الـ endpoints (اقرأ message)
400بيانات غير صالحة (المواد، المبيعات، الإعدادات، الأقساط)
401توكن غير موجود أو منتهٍ أو غير صالح، أو بيانات دخول خاطئة
403الاشتراك موقوف أو منتهٍ
404العنصر غير موجود أو لا يخص هذا المستخدم
405طريقة HTTP غير مدعومة في هذا الـ endpoint
409حذف مادة مرتبطة بمبيعات
429محاولات كثيرة (الدخول أو التسجيل)
500خطأ في السيرفر، والرسالة عامة دون تفاصيل تقنية

نقاط انتباه للمبرمج

  1. خزّن التوكن في flutter_secure_storage وليس في SharedPreferences.
  2. عند أي 401 امسح التوكن وأعد المستخدم لشاشة الدخول، وعند 403 اعرض رسالة إيقاف الاشتراك ولا تعِد المحاولة تلقائياً.
  3. بعد أي تعديل على مبيعات أو أقساط أو مخزن، أعد جلب /dashboard.php لتحديث الأرقام.
  4. استخدم ?search= لحقل اختيار المشتري بدلاً من جلب القائمة كاملة.
  5. أظهر stock_warning بعد كل عملية بيع، وأظهر subscription_remaining_days عندما يقترب من الصفر.
  6. نظام العملتين: اعرض المبالغ مع رمز العملة من الإعدادات (currency_symbol)، ولا تجمع USD مع LOCAL في رقم واحد.
  7. حذف المشتري أو عملية البيع لا رجعة فيه، فضع رسالة تأكيد قبله.
هذا التوثيق مبني على قراءة كود ملفات api/*.php الحالي. إذا تغيّر الكود فيجب تحديثه.
