# نشر النسخة على Hostinger

## 1) قاعدة البيانات
- اسم قاعدة البيانات: `aksat_aksatmaadmaad`
- اسم المستخدم: `aksat_maadnowaksat`
- كلمة المرور: ضعها في `api/config.local.php` فقط.

> هذه النسخة لا تحتوي على `setup.php` ولا تستخدم PREFIX. يجب أن تكون جداول النظام الأساسية موجودة في قاعدة البيانات قبل التشغيل.

## 2) PHP/JWT
إذا لم يكن `vendor/` موجوداً على السيرفر، افتح Terminal في مجلد المشروع وشغّل:

```bash
composer install --no-dev --optimize-autoloader
```

## 3) الواجهة
على جهاز التطوير:

```bash
npm install
npm run build
```

ثم ارفع **محتويات `dist/`** إلى `public_html/`، وارفع مجلد `api/` و`vendor/` حسب بنية المشروع.

## 4) ملف الأسرار
انسخ `api/config.local.php.example` إلى `api/config.local.php`، ثم ضع كلمة مرور MySQL الحقيقية. لا ترفع `config.local.php` إلى GitHub.

## 5) HTTPS
فعّل SSL/HTTPS قبل الاستخدام الفعلي.

## 6) الأدمن
أنشئ حساباً عادياً أولاً، ثم اجعل دوره `admin` من قاعدة البيانات أو من حساب أدمن موجود مسبقاً. لا يوجد بريد أدمن ثابت داخل ملفات المشروع.

## 7) بعد التشغيل
اختبر: التسجيل، الدخول، إضافة مادة، إضافة مشتري، بيع بالتقسيط، دفع قسط، التقرير، المخزون، ولوحة الأدمن.
